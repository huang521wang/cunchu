# 工作台 × QQ 官方机器人（本地连接程序）

这个程序让「我的工作台」能通过**腾讯官方的 QQ 机器人平台**在 QQ 里为你服务：
你在 QQ 里 @机器人 说「今天」，它就把工作台的每日简报（今日任务 + 作业截止）回给你。
全程走腾讯官方接口，**不碰你的 QQ 账号、读不到私人聊天**（官方也不提供这种能力）。

## 第一步：申请机器人（只有这步需要你本人做）

注册要用你的 QQ 登录 + 实名认证，我替不了，但几分钟就能搞定：

1. 电脑浏览器打开 **https://q.qq.com**，用**手机 QQ 扫码**登录。
2. 按提示**注册开发者**（需要实名认证，通常几分钟）。
3. 创建一个**机器人**，名字随便起（比如「我的工作台助手」）。
4. 进入机器人管理页面 → **「开发设置」**，找到并复制这两样：
   - **AppID**（一串纯数字）
   - **AppSecret**（一串字母数字，这就是密钥，别发给别人）
5. 在「发布」或「上线」区域看看有没有"沙箱/测试"的说明：刚建好的机器人通常先用**沙箱/测试环境**（本程序的 `sandbox: true` 就是配这个；机器人正式发布后把 `sandbox` 改成 `false`）。

## 第二步：填配置

把本文件夹里的 `config.example.json` **复制一份改名为 `config.json`**，用记事本打开填：

```json
{
  "appId": "你的 AppID（数字）",
  "secret": "你的 AppSecret",
  "sandbox": true,
  "workbench": "http://127.0.0.1:8787"
}
```

> `config.json` 里是密钥，别上传网盘、别发群里，本仓库也已把它排除在版本管理之外。

## 第三步：启动

1. 先双击 **「启动工作台.bat」**（工作台要开着，本程序要读本机数据）。
2. 再双击本文件夹的 **「启动机器人.bat」**。
3. 看到 `机器人已就绪 ✓` 就成功了。

想先检查配置对不对：打开命令行运行 `node bridge.mjs --check`。

## 在 QQ 里怎么用

- 把机器人**拉进一个群**（按机器人后台的指引），然后在群里 @它；如果你的机器人开通了单聊，直接私聊也行。
- **快捷命令（秒回）**：
  - `今天` / `日报` → 今日简报
  - `作业` → 还没做完的学习任务
  - `明天` → 明天截止的作业
  - `任务` → 今天没完成的任务
  - `帮助` → 使用说明
- **随便聊天**：说别的任何话，都交给**工作台里当前选中的模型**回答（设置里换了模型，QQ 里跟着换；自动带上记忆树）。
  - 回答前会先回一句「🤔 收到，我让工作台里的模型想想…」——本机模型通常 10~60 秒，请稍等。
  - 聊过的内容会**存进工作台的对话记录**（电脑上「AI 助手-对话」里能看到，带日期分组）。
  - 最近 3 轮对话会被记住当上下文（重启连接程序会忘，这是临时的）。
- **让它帮你记录**：说「加任务：明天交方案」「备忘：买牛奶」「记体重：55.5」「打卡：卧推+2.5kg」「记饮食：鸡胸肉饭」「记住：我周末不接电话」——
  - 它会先问一句「要……吗？回复 1 确认、2 取消」，你回 **1** 才真写进工作台，回 **2** 就取消。

## 边界（说清楚）

- 机器人**只能回答你主动问它的内容**，读不到你和其他人的聊天记录——这是腾讯官方的限制，也是我们做这个程序的底线。
- 你问机器人时，问题和你工作台生成的那段回复**会经过腾讯服务器**（官方通道转发的正常现象）；工作台数据本身仍只存在你自己电脑上。
- 申请机器人是免费的；个人开发者按腾讯平台当时的审核要求为准。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示"配置还不完整" | `config.json` 没建或 AppID/Secret 填错 |
| 提示"连不上工作台" | 先把「启动工作台.bat」开着 |
| 拿不到网关地址 HTTP 401 | Secret 复制不全或不对，去后台重新复制 |
| 能连上但 @它没反应 | 机器人还没"发布/上线"；或还在沙箱环境，把 `sandbox` 改成 `false` 再试（或按后台说明用沙箱） |
| 关了黑窗口就收不到回复 | 本程序的窗口要一直开着（和数据是本地的是一回事） |
