# AI 助手 · 功能分类索引（一个文件夹对应一个功能）

> 用途：看包识功能。备份包解开后照此表找东西。程序名「AI 助手」，包名=程序名+版本号。

| 功能 | 位置（app/ 下） | 说明 |
|---|---|---|
| 主服务与聊天大脑 | server/server.js | 工作台后端核心（聊天多模型路由、集合 CRUD、拟人化调度） |
| 记忆树 | server/server.js(memory 段) + D:\AI助手记忆 | 三层去重、文件双向同步 |
| 知识库 | tools/知识库/build-kb.mjs + D:\知识库 | 9 类知识 + MCP 服务 + 申请审批制 |
| 学习通桥 | server/xxtsync.js xuexitong.js xxttask.js | 直连同步/作业草稿/读题/确认提交 |
| 邮箱通知桥 | server/mailwatch.js | IMAP 收学习通邮件（备用通道） |
| 拟人化生命体 | server/persona.js | 柳月虹作息状态机 |
| QQ 机器人 | tools/qqbot/bridge.mjs | 官方网关长连接、被动/主动消息 |
| AI 画图 | server.js(/api/imagine) + Assistant.tsx 对话命令 | 云端智谱 CogView，对话里「画：xxx」 |
| 图片识别 | server.js(vision 段)+xxttask.js | OCR/看图/预识别缓存 |
| 外网访问 | tools/外网访问-云服务器/frps-windows.ps1 + tools/外网访问 | frp+Caddy 固定入口（部署脚本存档） |
| 开机自启 | autostart-workbench.vbs + tools/qqbot/autostart-bridge.vbs + tools/frp/*.vbs | 三件套 |
| 前端界面 | web/src（pages 页面 / components 卡片 / theme.css 主题） | 聊天、设置、学习、健身……一页一功能 |
| 测试 | test/（单元 152）+ e2e/（端到端 90） | 提交前必全绿 |

## 永不进包的东西（账号/密钥/数据，只在本机）

- data/（数据库全部：聊天记录、Cookie、密钥）
- app/tools/qqbot/config.json、bridge-state.json（QQ 身份）
- tools/frp/（隧道二进制+token）
- .shots/（临时脚本）
