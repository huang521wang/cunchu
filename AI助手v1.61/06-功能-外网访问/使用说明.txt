# 工作台「外网访问」使用说明

这个文件夹让你**不在家、不在同一 WiFi 的时候**，也能在手机/任意浏览器上使用完整的工作台。

## 怎么用（三步）

1. 双击本文件夹的 **「启动外网访问.bat」**：
   - 它会**先检查工作台在不在**；不在就自动帮你启动（会开一个最小化窗口，别关它）；
   - 然后黑窗口里会出现一个网址，形如 `https://xxxx-xxxx.trycloudflare.com`（等几秒）。
2. 在外面用手机/电脑浏览器打开那个网址 → 输访问口令 → 就是完整的工作台。
3. **用完双击「关闭外网访问.bat」**（或直接关掉黑窗口），外网立刻断开。

## 这次做的优化

- **页面压缩**：传输体积小了约 70%（JS 377KB → 110KB），外网打开明显更快
- **静态资源长缓存**：同一网址下再打开几乎秒开
- **更稳的通道**：默认走 HTTP/2 + IPv4（学校/手机网络下比 UDP 通道更容易通）
- **自动检查工作台**：工作台没开时会自动帮你开，不会再出现"网址能通但里面打不开"
- **断线自动重连**：网络抽风断开后自动重连（注意：**重连后网址会变**，以新出现的方框为准）
- **一键关闭**：「关闭外网访问.bat」

## 安全说明（重要）

- 外网访问**必须输访问口令**（6 位数字，电脑「启动工作台」窗口里显示；输错 5 次锁 5 分钟）
- 网址是每次启动**随机生成**的（很长、猜不到），关掉窗口即失效
- 数据仍然只在你自己的电脑上——`trycloudflare.com` 只是"通道"（Cloudflare 官方服务）
- 不太放心的话：只在需要的时候开，用完就关

## 怎么看到本次网址

双击启动后，黑窗口里会出现一个**方框**，框里那一行就是本次网址：

```
+-----------------------------------------------+
|  https://xxxx-xxxx-xxxx.trycloudflare.com      |
+-----------------------------------------------+
```

鼠标拖选那行即可复制；每次启动都不一样，**以窗口里当次的为准**。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 网址打不开 / 转圈 | 国内到 Cloudflare 有时不稳，**多刷新几次**或等一分钟重试 |
| 提示"需要访问口令" | 输电脑窗口里那 6 位数字 |
| 提示"口令错误次数太多" | 等 5 分钟，或到电脑上改 `data\lan-access.json` 换一个口令 |
| 窗口里一直没出现网址 | 先确认电脑能上网；启动器会自动帮你开工作台，若仍失败，手动双击「我的工作台」再试 |
| 通道断开后自动重连了 | 正常；**用新方框里的新网址**（旧网址失效） |
